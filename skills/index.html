How to install

5 minutes
  1. In Claude, turn on code execution: Settings > Capabilities.
  2. Download a skill below. Each one is a single zip.
  3. Upload it: Customize > Skills > + > Upload a skill. Repeat for each zip.
Using Claude Code? Unzip into your skills folder instead: 
unzip grill-me.zip -d ~/.claude/skills/

01

/grill-me

By Matt Pocock

Claude interviews you until every open question in the plan is answered. Each round comes with its recommended answer, so you only push back where it matters. You find the hole before it costs you a week.

Use it before you build anything

02

/handoff

By Matt Pocock

Compresses the whole chat into one doc: the goal, what is decided, what is open, and the next step. Paste it into a new chat and pick up exactly where you stopped.

Use it before you close a chat you haven't finished

03

/big-three

By Lior Pozin

Every morning it asks which two or three things you commit to today. It checks in during the day. Friday it shows committed versus done, and at month end, the big things you actually finished.

A long to-do list feels productive. Most of it is a shopping list.

Use it every morning
