Get it: pick your setup

2 minutes

I use the Claude app

  1. Download the skill
  2. In Claude, turn on Settings > Capabilities > Code execution
  3. Go to Customize > Skills > + and upload the file
  4. Write: Make an HTML plan for and what you want to build

I use Claude Code or Codex

  1. Copy this line 
    npx -y skills add anthropics/claude-plugins-community --skill html-plan
  2. Paste it in your terminal and press Enter
  3. Write: /html-plan and what you want to build
